# 单机突击玩法改造

玩家驾驶一架飞机，以瞄准、机动和投弹时机夺取制空权并击沉两艘航母。保留现有海面、岛屿、舰船管理和 GLB 离线入口，不引入框架。

循环：迎击拦截机 → 观察舰炮曳光与爆炸预警 → 改变高度/航向躲避 → 对准预测落点投弹 → 拉起脱离 → 飞越友舰补给区 → 再次攻击。机炮击杀减少追击压力并增加分数；炸弹削弱并最终摧毁目标；血量归零、撞海/撞舰导致失败，可立即重试。

操控：鼠标控制俯仰与转向；W/S 油门；A/D 转弯；方向键俯仰；Q/E 滚转；Shift 消耗加力能量；R 桶滚；左键机炮；Space 投弹；Tab 切换敌舰；P 暂停。触屏发出同一套输入意图。允许选 F4U 或喷火外观，属于架空街机战役。

技术：固定 1/60 秒物理；飞机球体与子弹相对运动扫掠检测；炸弹与舰船 OBB 扫掠；舰炮实体抛射物/延时定点破片云。桶滚改变飞机实际位置，不提供无敌。投弹继承飞机速度与重力，不自动追踪。镜头保持地平线可读，只部分跟随机翼倾斜。机炮过热、加力能量、炸弹库存限制持续无脑输出。

遭遇：起始高度 150m，敌舰位于约 1.3km 前方；首批两机可被发现并交战；每 30 秒有限补充拦截机，上限6；驱逐舰射速更快且可被炸弹清除，形成削弱防空或优先打航母的决策。敌舰附近高空定时高射炮与低空直射交织；友舰半径180m、高度40–180m区域连续飞行2秒补给，恢复弹药和部分血量。

验证：真实浏览器输入驾驶/开火/投弹/桶滚、暂停与重试、触屏布局；确定性测试子弹扫掠/闪避、炸弹惯性与碰撞、防空可躲性、过热与冷却、补给、胜负条件和对象预算。资产原文件不改动，附署名；新模型做方向/水线校准。
